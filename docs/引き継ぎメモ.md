### 踏んだ不具合（同じ轍を踏まないこと）
- **スワイプの実行判定に「画面幅の◯割」を使ってはいけない。** 幅が0と報告される場面があり、
  しきい値も0になって**ほんの少し滑らせただけで削除が走った**（実データを1件ゴミ箱に入れてしまい復元）。
  ボタン幅を基準にした固定距離で判定する。
- **`?? 320` は 0 を弾けない。** 既定値を入れるつもりが 0 のまま通る。0を弾くなら `|| 320`。
- **pointermove と pointerup が同じ処理の中で連続して届くことがある。** Reactの状態は次の描画まで
  更新されないため、指を離した判定は必ずrefの値で行う。
- **リストを空Enterで抜けるときは空行を1つ挟む。** 挟まないと次に書いた行がMarkdownの決まりで
  直前のリスト項目に飲み込まれる。
- **iOSは16px未満の入力欄にフォーカスすると画面を拡大する。** メモの検索欄・本文が13〜15pxだったため
  スマホで書くたびに拡大されていた。base に「スマホ幅では入力欄16px」を入れて回避（アプリ全体に効く）。
- **pointermove はマウスが通り過ぎただけでも発火する。** 押しているかを見ていなかったため、
  PCでカーソルを重ねただけで行が横に滑った。押下中のポインタIDを控え、
  マウスは `buttons === 0`（離している）なら操作を打ち切る。**指では起きないのでPCで必ず確認すること。**

## ハマりどころ（実際に起きた/起きうる問題と対策）

### 6. Next.js 14.2.15にミドルウェア認証バイパスの重大CVE【今回対応済み】
- `x-middleware-subrequest` ヘッダでミドルウェアを素通りできる脆弱性（CVE-2025-29927）。ログイン必須化が無意味になるところだった。
- **対策**: 14.2.35へ更新済み。`npm audit` に残る警告はNext 15/16でしか直らないもの（DoS系中心）。将来Next 15へ上げる。

### 7. FormData の priority が Number(null)=0 になる罠【今回対応済み】
- ダッシュボードのクイック追加には優先度欄が無く、`Number(formData.get("priority"))` が `Number(null)=0`（低）になっていた。
- **対策**: `formData.get()` の null を先に判定してからデフォルト「中(1)」を適用。

### 8. Server Actionのフォームは送信後に入力が残る
- `<form action={serverAction}>` はNext 14では自動リセットされない。
- **対策**: `src/components/AutoResetForm.tsx`（アクション完了後に form.reset() する客側ラッパー）を全入力フォームで使用。

### 9b. Tailwindで CSS変数色に透明度修飾子は使えない
- 色を `var(--line)` のように定義すると、`divide-line/60` や `ring-accent/50` はビルドエラーまたは無効になる。
- **対策**: 透明度は変数側に焼き込む（`--line: rgba(60,60,67,0.15)`）。修飾子が必要な箇所は `ring-[rgba(0,122,255,0.45)]` のようにリテラルで書く。

### 9. GCP同意画面「テストモード」のrefresh tokenは7日で失効（フェーズ2の前提）
- Gmail readonlyはrestrictedスコープで、個人利用は審査を通さずテストモード運用が現実解。ただしテストモードのトークンは7日で切れる。
- **対策（設計済み）**: 連携カードに状態表示+「再連携」1タップ導線。失効しても他機能は動くフェイルセーフにする。
